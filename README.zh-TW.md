# Floor Plan Editor

輕量、離線可用的 2D 平面圖與立面圖編輯器，同時能產生素材（線稿 PNG + 文字提示詞）交給
Gemini/Imagen 這類外部 AI 算圖模型使用。

不用安裝、不用架伺服器、不用註冊帳號。下載整個資料夾，雙擊 `index.html` 就能開始畫。

[English version: README.md](README.md)

## 特色

- 純前端單頁應用程式，完全離線可用，所有函式庫都放在本機 `vendor/` 目錄
- 在無限大、有吸附、可縮放的畫布上繪製房間、家具、門窗、插座
- 立面圖模式（上/右/下/左/天花板/地板 6 個視角）由平面圖資料自動投影產生，不用另外重畫
- AI 匯出：2×3 六宮格純線稿 PNG ＋ 可直接複製貼上的文字／JSON 提示詞，讓你把平面圖交給
  AI 算圖模型換回一張擬真渲染圖
- 內建英文與繁體中文介面，之後要加其他語言也很容易（見本文件最下方）

## 開始使用

1. 下載或 `git clone` 這個專案
2. 用瀏覽器（Chrome、Firefox、Safari、Edge 皆可）開啟 `index.html`——直接雙擊，或想用
   靜態伺服器開也可以（例如 `python3 -m http.server`）
3. 開始畫圖

畫的過程中會自動存到瀏覽器本機儲存空間（見下方「自動儲存」），不用特別記得存檔。

## 使用手冊

### 房間

在左側工具列選「房間」工具，在畫布上按下、拖曳、放開即可畫出矩形房間。拖曳過程中邊緣會
自動吸附格線與其他房間。選取房間後，右側面板可編輯名稱、寬/深、填色，以及精確的 X/Y
位置與尺寸——面板直接輸入數字時，5 cm 內也會自動吸附鄰近房間的邊緣。

### 家具、燈具與結構元件

左側工具列的「家具」子選單分三類：

- **家具**：矩形／圓形／三角形，用來抽象代表沙發、桌子、床等任何物件
- **結構**：樑
- **燈具**：吸頂燈、立燈、檯燈

在房間內按下、拖曳、放開即可以合理的預設尺寸放置（跟房間不同，家具放置時不是拖出自訂
尺寸，放好後再用選取控點調整大小）。物件必須完全落在某個房間內，或是完全落在幾個相鄰
房間合併範圍內（例如橫跨開放式空間的物件）；放置不合法時會顯示簡短提示並還原。

選取物件後可編輯名稱、尺寸、填色、位置與旋轉角度（直接輸入 0–359° 的角度，或用
「↻ 90°」快速旋轉按鈕）。物件上永遠有一個小箭頭標示「正面」方向。

### 門窗與插座

「開口」工具用來放置門和窗：拖曳到房間牆線附近會自動吸附上去，拖曳過程中會顯示即時
十字準心。放置後可在右側面板微調沿牆的位置、離地高度、物件本身高度。同一面牆上兩個
開口不能重疊，不合法的位置會被拒絕並顯示簡短提示。

「插座」工具可以在房間內任意位置放置插座，高度欄位跟開口相同。

### 選取、多選與對齊

- **選取工具**：點擊物件即可選取
- **Shift／Ctrl + 點擊**：加入選取
- **在空白畫布拖曳**：框選範圍內所有物件
- **按住空白鍵拖曳**：平移畫布
- **方向鍵**：微調目前選取項目 1 cm
- **Delete／Backspace**：刪除目前選取項目
- 選取 2 個以上物件時，右側面板會出現批次「對齊」（靠左/右/上/下、水平置中/垂直置中）
  與「全部刪除」

### 立面圖模式

頂欄的「立面圖」按鈕（至少有一個房間後才會啟用）可以從平面圖切換到逐面牆的視角。先選
房間，再選視角頁籤——頁籤名稱代表「你站的位置」，例如「上」頁籤看到的是你站在房間上方、
往下方牆看過去的畫面。「天花板」與「地板」則分別是反射天花板圖與俯視平面圖。

這裡看到的每個物件都有同一組三個高度欄位（離地／物件高度／離天花板）——任意編輯其中
兩個，第三個會依房間的天花板高度自動算出，不需要鎖定圖示，系統只是自動追蹤你最近動過
的兩個欄位。沒有旋轉過的物件還有可編輯的水平位置欄位（距左／距右／寬度），會直接寫回
平面圖；旋轉過的物件這裡會顯示唯讀，因為這個視角看到的寬度跟它實際存的寬度不是同一個
數字——要調整請回平面圖模式。

畫面右上角的 minimap 會把目前房間整個標亮，如果目前是牆面視角，還會在那面牆上畫一個
指向房間內側的箭頭——這是沿用建築製圖裡「立面標記」的慣例畫法。

### AI 匯出

點頂欄的「AI 匯出」（有房間後才會啟用）。勾選一或多個房間，選一個風格預設（工業風／
北歐風／現代極簡）或自己輸入——自訂風格建議用英文描述，因為最終是要交給以英文為主的
算圖模型。選了多個房間時，可以在「個別房間」跟「合併」兩種模式間切換，合併模式會把
所有房間拼成一張六宮格大圖跟一份綜合提示詞。

每個房間（或合併結果）會提供：

- **六宮格 PNG**：白底純黑線條的六視角線稿，設計成上傳給算圖模型當參考／草圖圖片
- **提示詞**：一段可直接複製貼上的英文句子，描述房間、風格，以及要避免的內容
- **JSON 提示詞**：同樣的資訊整理成結構化 JSON，給比較擅長解析結構化輸入的模型用

建議流程：下載 PNG → 上傳給算圖模型當參考圖 → 貼上提示詞或 JSON 提示詞 → 產生。

### 設定

齒輪圖示可以開啟設定：單位（目前只有公制，英制規劃中）、預設牆厚、介面語言、格線
顯示／間距／顏色。

### 自動儲存

每次改動幾秒後就會自動存進瀏覽器的本機儲存空間；頂欄也有一個「儲存」按鈕可以立刻強制
存檔，但一般情況下不需要特別想著存檔這件事。這是「這台瀏覽器、這台裝置」專屬的儲存，
不會跨裝置同步，清除網站資料也會一併清掉。

## 目前還沒做的功能

老實列一下這個版本還沒有的東西：開新專案／從硬碟開啟舊檔案、復原／重做、把畫好的平面圖
匯出成 PNG／PDF、便條紙功能。這些在介面上都有看得到但無法點擊的按鈕，不是藏起來的功能
或壞掉，單純還沒做。

## 技術棧

- [Konva.js](https://konvajs.org/) — Canvas 繪圖與互動引擎
- [Vue 3](https://vuejs.org/) — UI 狀態管理（Composition API，無 build step，用
  `<script>` 標籤直接載入）
- 所有依賴都放在本機 `vendor/` 目錄，執行時不會對外發任何網路請求
